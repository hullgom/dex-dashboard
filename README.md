# DEX 대시보드

갤럭시 Z 폴드8 + 덱스(DeX) 모드로 보조 모니터(제우스랩 P16TK)에 띄워 두는 대시보드입니다.
API 키나 회원가입 없이 동작합니다.

| 영역 | 데이터 | 갱신 |
|---|---|---|
| 시계·날짜·장 상태 | 기기 시계 (한국 시간) | 1초 |
| 날씨·미세먼지 | Open-Meteo (무료, 키 불필요) | 10분 |
| 구글 캘린더 | Google Calendar 공식 임베드 | 30분 |
| 삼성전자·SK하이닉스 | 네이버 금융 차트 이미지 (당일/일봉/주봉/월봉) | 1분 |
| SOXL | TradingView 위젯 (실시간에 가까움, 기간 선택 가능) | 자동 |

> TradingView 무료 위젯은 한국거래소(KRX) 종목을 지원하지 않아서 국내 종목은 네이버 금융 차트를 씁니다.
> 차트를 탭하면 네이버 증권 종목 페이지가 열립니다.

## 1. 인터넷에 올리기 (GitHub Pages, 무료)

1. github.com 에 로그인 → 오른쪽 위 **+ → New repository** → 이름 `dex-dashboard`, **Public** 으로 생성
2. 새 저장소 화면에서 **uploading an existing file** 클릭 → 이 폴더의 파일 전부(`icons` 폴더 포함)를 끌어다 놓고 **Commit changes**
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. 1~2분 뒤 `https://<내 깃허브 아이디>.github.io/dex-dashboard/` 에서 열립니다.

(https 주소여야 앱 설치·현재 위치·화면 꺼짐 방지가 동작합니다.)

## 2. 덱스에서 앱처럼 실행하기

1. P16TK를 USB-C(영상 지원 포트)로 폴드8에 연결 → 덱스 화면이 모니터에 뜹니다.
2. 덱스에서 **Chrome** 실행 → 위 주소 열기
3. Chrome 메뉴(⋮) → **홈 화면에 추가 → 설치** (삼성 인터넷이라면 메뉴 → 현재 페이지 추가 → 홈 화면)
4. 덱스 바탕화면/앱스에서 **대시보드** 아이콘 실행 → 전체화면 앱으로 열립니다.
   창 모드로 뜨면 창을 최대화하거나 오른쪽 아래 ⛶ 버튼을 누르세요.
5. 마우스를 4초간 움직이지 않으면 커서와 버튼이 숨겨집니다.

화면 꺼짐: 대시보드가 화면에 보이는 동안은 꺼짐 방지(Wake Lock)를 요청합니다.
그래도 꺼지면 폰의 **설정 → 디스플레이 → 화면 자동 꺼짐 시간**을 늘려 주세요.

## 3. 설정 (오른쪽 아래 ⚙)

- **날씨 지역**: 기본 서울. "현재 위치" 버튼 또는 위도/경도 직접 입력
- **구글 캘린더 ID**: 기본 캘린더는 내 Gmail 주소. 다른 캘린더 ID는
  구글 캘린더(PC) → 캘린더 설정 → **캘린더 통합 → 캘린더 ID**. 여러 개면 쉼표로 구분
- 캘린더/국내 차트 어둡게 표시(색 반전) 켜기·끄기

설정은 그 기기 브라우저에만 저장됩니다.

### 캘린더가 "권한 없음"이나 빈 화면으로 나올 때

비공개 캘린더 임베드는 **같은 브라우저에 그 구글 계정으로 로그인**되어 있어야 보입니다.

1. 같은 Chrome에서 calendar.google.com 에 로그인
2. 그래도 안 보이면 Chrome **설정 → 개인정보 보호 및 보안 → 서드 파티 쿠키 → 서드 파티 쿠키 사용이 허용된 사이트 → 추가** 에서 `[*.]google.com` 추가
3. 최후의 방법: 캘린더를 "공개"로 바꾸면 로그인 없이 보이지만, 주소를 아는 누구나 일정을 볼 수 있으니 권장하지 않습니다.

## 파일 구성

- `index.html` / `style.css` / `app.js` — 대시보드 본체
- `manifest.webmanifest` / `sw.js` / `icons/` — 앱 설치(PWA)용
- 종목을 바꾸려면 `index.html`의 `data-code="005930"`(국내 종목코드) 또는 `data-symbol="AMEX:SOXL"`(해외)을 수정하세요.
